# Renem

A modern, AI-powered language learning Flutter application.

## Overview
- **Modular Architecture**: Clean separation into `models/`, `services/`, `screens/`, and `widgets/`.
- **Focused AI Learning**: Personalized learning tracks (neutral, daily life, career, travel, media, exam).
- **Multi-Provider AI Router**: Fast failover across Google Gemini, Groq, and NVIDIA NIM with session rate-limit recovery.
- **Comprehensive Grammar Handbook**: 9 in-depth grammar chapters with declension/conjugation tables, TTS examples, and interactive AI Q&A.
- **CEFR Mastery Path**: Adaptive modules, duel challenges, pronunciation trainer, and spaced-repetition vocabulary practice.

## Getting Started
1. Install Flutter dependencies:
   ```bash
   flutter pub get
   ```
2. Run the application:
   ```bash
   flutter run
   ```
